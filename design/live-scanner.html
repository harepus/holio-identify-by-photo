Live scanner in the demo shell

Serves Holio's brief, pain 3: a pack with a code the register does not know. Today the demo scanner is drawn and scans come from buttons. With a live camera the jury sees the real moment: scan a real pack, the code is unknown, identify it by photo, link the code, and the next scan of that pack receives it.

Demo shell only. The IdentifyByPhoto component does not change, because Holio Ops already has its own scanner. The simulate buttons stay for PCs and for phones without camera access.

States of the viewfinder

1. Starting

Starting the camera

While the browser asks for camera access.

2. Scanning

Point at the barcode

Live back camera fills the frame. Reads EAN-13, EAN-8, UPC-A, UPC-E and Code 128.

3. Code read

7038010009457Point at the barcode

The code goes to the same handler as a simulated scan. Known code: received, toast. Unknown code: the unknown-code sheet. The same code is ignored for 2.5 s, so one pack is not counted twice.

4. Camera blocked

Camera access is off. Allow it in the browser settings, or use the buttons below.

Permission denied, or no camera.

5. Not HTTPS

Open this page over HTTPS to scan with the camera. The buttons below still work.

Browsers give the camera only to HTTPS pages and localhost.
